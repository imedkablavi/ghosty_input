# Privacy

Ghosty Input is designed to run locally.

- Camera frames are processed in memory.
- The application does not upload frames, hand landmarks, typed keys, or mouse activity.
- No analytics, telemetry, remote logging, or cloud API is included.
- Settings and calibration data are stored locally in the user's application-data directory.

Third-party Python packages are downloaded only when you install the project with `pip`. After installation, Ghosty Input itself does not require an internet connection.
